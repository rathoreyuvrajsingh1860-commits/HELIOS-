# HELIOS — Interactive Solar System Simulation

A self-contained, dependency-free simulation of the solar system, built with vanilla HTML5 Canvas and JavaScript.

**[Live demo →](https://rathoreyuvrajsingh1860-commits.github.io/HELIOS-/helios.html)**

## Features
- All 8 planets orbiting the Sun with real relative distances and sizes (toggleable "true scale" mode)
- Moons: Earth's Moon, Mars' Phobos & Deimos, Jupiter's 4 Galilean moons, Saturn's Titan, Uranus' Titania, Neptune's Triton
- Asteroid belt between Mars and Jupiter
- A comet on a real eccentric elliptical orbit with a fading tail
- Motion trails and visible axial rotation for each planet
- Live simulated calendar date that advances with simulation speed
- Adjustable simulation speed, pause/play, orbit & label toggles
- Pan (drag), zoom (scroll wheel or pinch on touch devices), and click-to-inspect any body
- Keyboard shortcuts: `Space` to pause, `←`/`→` for speed, `+`/`-` to zoom
- Zero dependencies, zero build step — a single HTML file

## Run it
Just open `helios.html` in any modern browser, or visit the live demo link above.

## Tech
Vanilla JS, HTML5 Canvas, CSS. No frameworks, no npm install, no build tools.
